Forecasting truck traffic at Tanger Med

For my end-of-studies internship at Tanger Med Special Agency (2025), I collected, cleaned and analysed more than 7 million rows of import and export truck data, then forecast the flows with MLP, LSTM and ARIMA models.

Results went into Power BI dashboards for tracking key indicators, and into a Streamlit app where decision-makers explore predictions and generate recommendations. I presented it to the Data & Performance team.

Python, Keras, Statsmodels, Power BI, Streamlit

Projects I built end to end

QuantStream

A real-time crypto analytics platform that simulates pairs trading. BTC and ETH ticks stream in from Binance over WebSocket and go through Apache Kafka, with every service containerised in Docker Compose.

A statistical engine runs a cointegration test on a rolling window of 100 ticks and turns the spread’s z-score into buy and sell signals. A Spring Boot microservice on PostgreSQL executes simulated trades, and a Next.js dashboard shows prices, signals and balance.

Python, Kafka, Statsmodels, Spring Boot, PostgreSQL, Next.js

ShopEase

A multi-role e-commerce platform in Java with Servlets, JPA/Hibernate and SQL Server. JWT authentication separates three roles: customer, seller and administrator.

The Jenkins pipeline builds with Maven, runs 139 unit tests (JUnit, Mockito), checks code quality with SonarQube, publishes a Docker image to Docker Hub, deploys and pings Slack. Prometheus collects metrics from the running app and Grafana dashboards display them. A scheduled job updates order statuses automatically.

Java, Hibernate, SQL Server, JWT, Docker, Jenkins, SonarQube, Prometheus, Grafana
